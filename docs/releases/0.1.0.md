# MARS 0.1.0

The first official stable release of the MCP Astronomy Research Suite,
following the `0.1.0rcN` testing series. It includes the M1–M6 release work
that was absent from `0.1.0rc6`.

MARS provides 55 astronomy tools through the local `mars-mcp` stdio server,
plain Python functions and the `mars` console. The supported Python versions
are 3.12 and 3.13. Desktop launchers select Python 3.13.

## Changes since 0.1.0rc6

- **Scientific results:** corrected pulsar channel, period/frequency and
  confidence semantics; variable-star power and uncertainty handling; WCS
  acceptance and detector-footprint geometry; catalog parsing, matching and
  photometric calibration edge cases. Corrections have focused correctness
  regressions alongside the preserved upstream baselines.
- **HR fitting:** reports the settings and age grid used. The agent can vary
  `track_max_gap_mag` on the same members table and compare fits; its default
  remains 0.5 mag. A fit tuned toward literature values must disclose that
  tuning and does not independently confirm those values.
- **Failures and resource control:** structured errors distinguish invalid
  inputs, unavailable services and resource limits. Owned workers support
  cancellation and bounded memory, downloads, disk use and responses.
  Scientific warnings survive handled computation and artifact failures.
- **Installation and console:** updated desktop/platform guidance, catalog
  folder discovery, actionable setup errors and console controls. A stopped
  model reply now preserves the question for immediate follow-up and saved
  session reopening, including when a partial answer had streamed.
- **Optional data:** HTTP bundle transfers stop before writing beyond the
  pinned archive size, including resumed transfers. Archive checksums and
  extracted-tree verification remain required. The existing content-addressed
  optical and isochrone bundles are unchanged.
- **Python calibration:** WCS-free matching retains valid sky-coordinate
  references when only some catalog rows also contain pixel coordinates, and
  retains pixel-only references in mixed catalogs. Competing associations
  across the coordinate domains are withheld with an explicit diagnostic.
- **Publication:** the same source, data and licence verification runs before
  publication and during release dry runs. The GitHub release includes these
  versioned notes, the wheel, source archive, `mars.mcpb` and `SHA256SUMS`.

## Install or upgrade

```sh
uv tool install --force --python 3.13 "skynet-mars[mcp]==0.1.0"
mars-mcp self-test
```

[Install and register with a host](https://github.com/SkynetRTN/MARS/blob/v0.1.0/docs/installing.md).
Claude Desktop users can install the attached unsigned `mars.mcpb` on Apple
Silicon macOS or Windows on ARM. Its launcher selects the newest stable MARS
release on restart; its *MARS release* setting can pin `0.1.0`.

The wheel carries core examples and the agent guide. Install the optional
optical frame library and Girardi grid with `mars-mcp fetch-data all`.
Plate solving additionally needs operator-installed astrometry.net and
suitable index files. API credentials remain necessary for services that
require them, including ADS literature tools.

Recompute older pulsar spectra before using the current confidence thresholds;
older artifacts may lack the current channel and calibration metadata.
Consult the result warnings and the extraction record when comparing answers
with prerelease output.

## Support and retained limits

Supported platforms are Linux x86_64/ARM, Apple Silicon macOS and Windows on
ARM using x64 Python under emulation. Codex in the ChatGPT app on macOS remains
untested. The MCP server is a trusted local single-user interface.

The [known limitations](https://github.com/SkynetRTN/MARS/blob/v0.1.0/docs/limitations.md)
remain part of this release's support scope. Preserved upstream parity does
not establish scientific correctness; HR fits provide no parameter
uncertainties, catalog/filter approximations remain disclosed, and pulsar
confidence assumes the documented noise model. Benchmark scores apply only
to their recorded corpus, with provider/dialect and selection biases.

Live astronomy-service and model-provider checks, and post-SciX ADS
revalidation, were waived by the maintainer for this release. Service
availability is therefore a disclosed validation limit. Detailed checks and
remaining publication evidence are recorded in the
[release evidence](https://github.com/SkynetRTN/MARS/blob/v0.1.0/docs/analysis/m6-release-evidence.md).
