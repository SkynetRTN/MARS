# 0.1.0 dependency security review

Reviewed 2026-11-13 during preparation of the first official stable release.
The candidate's push reported open Dependabot alerts, so the earlier plan to
leave all dependency versions unchanged was reopened under the security-update
exception in [the release procedure](../releasing.md#supply-pins-and-updates-aud-02).

## Observed scope

GitHub's authenticated repository alert API reported 51 open alerts against
runtime packages in the baseline `uv.lock`: six critical, 26 high and 19
medium. They concern five packages. The advisory inventory was read directly;
none of the representative advisories below was withdrawn. The candidate must
resolve every recorded affected-version range before release approval.

| Package | Locked baseline | Required minimum | Placement | Baseline alerts |
|---|---|---|---|---|
| Pillow | 12.3.0 | 13.0.0 | Base runtime | 43, including five critical |
| certifi | 2026.7.22 | 2026.10.18 | Base runtime | One critical |
| Soup Sieve | 2.9.2 | 4.0.0 | Base runtime | Two high, two medium |
| Werkzeug | 3.1.8 | 3.1.9 | Base runtime | One medium |
| OpenTelemetry API | 1.44.0 | 1.45.2 | Optional MCP runtime | Two medium |

Primary advisory records:

- [Pillow JPEG decoder heap overflow](https://github.com/python-pillow/Pillow/security/advisories/GHSA-8g5g-8vmr-9782), representative of the Pillow findings whose first patched release is 13.0.0.
- [certifi compromised certificate-chain roots](https://github.com/certifi/python-certifi/security/advisories/GHSA-6q48-6c7w-9gw2), fixed in 2026.10.18.
- [Soup Sieve descendant-combinator denial of service](https://github.com/facelessuser/soupsieve/security/advisories/GHSA-mmhr-3c5m-f64f), published on the review date and fixed in 4.0.0. The earlier 3.0.2 fix does not cover this advisory.
- [Werkzeug advisory](https://github.com/advisories/GHSA-g6x2-hccm-hh4m), fixed in 3.1.9.
- [OpenTelemetry API advisory](https://github.com/advisories/GHSA-mf5v-w3w3-f6cg), fixed in 1.45.2; the earlier 1.45.1 fix covers a different advisory.

## Corrected candidate

Selective relocking chose Pillow **13.0.0**, certifi **2026.10.23**, Soup Sieve
**4.1**, Werkzeug **3.1.9** and OpenTelemetry API **1.45.2**. These are the only
five changed external package versions; the lock retains the same 97 package
names and MARS remains `0.1.0`. Every one of the 51 captured affected-version
ranges excludes its selected version. A separately rebuilt wheel's actual
`Requires-Dist` metadata also enforces the floors and the MCP-only marker.

Five requirement-admissibility regressions reproduced the old omissions;
50 focused metadata/publication tests pass with the correction. Independent
security review found no actionable issue in the dependency delta. These are
focused results; final integration at source revision `5b4cb58` also passed:

- [Supported-Python CI](https://github.com/SkynetRTN/MARS/actions/runs/43510390106):
  5,257 passed/101 skipped on Python 3.12 and 5,258 passed/100 skipped on
  Python 3.13, including the parser/rendering paths; both installed-wheel
  checks and macOS/Windows ARM native containment passed.
- Local Linux ARM full suite: 5,258 passed/100 skipped; affected Python 3.12
  paths: 293 passed; configured native solver checks: 257 passed.
- Fresh installed wheels on Python 3.12 and 3.13 passed protocol self-tests
  and installed guide content/hash verification. Wheel and sdist strict
  metadata/source/data/licence checks passed.
- [Release rehearsal](https://github.com/SkynetRTN/MARS/actions/runs/43513739275):
  passed, including both Python installs, native extensions and optional
  data across Linux/macOS/Windows. All publication jobs were skipped.
- [Secret scan](https://github.com/SkynetRTN/MARS/actions/runs/43510390087) and
  [workflow safety](https://github.com/SkynetRTN/MARS/actions/runs/43510390151):
  passed at the same source revision.

The extra Python 3.12 skip needs Python 3.13 for a launcher test covered by
the 3.13 job. Both full CI suites retained 230 expected FITS notices; native
data and live-provider skip handling remains explicit in the
[M6 evidence](m6-release-evidence.md#5-official-010-preparation-2026-11-12).
These results validate the dependency correction without waiving new failures.

## Correction and validation contract

The correction is limited to these five dependency versions and the metadata
needed to enforce their security floors. Pillow's compatible-major bound moves
to 13. The transitive minima are declared in distribution metadata as explicit
security exceptions to the usual direct-import-only dependency rule. This also
protects a wheel installed without `uv.lock`; fixing only the development lock
would leave older vulnerable versions admissible. OpenTelemetry stays in the
MCP extra rather than becoming a dependency of SDK-free installations.

No scientific array, fitting or catalog-transform dependency is refreshed as
part of this correction. Selective relocking must report any additional version
change rather than hiding it in a blanket upgrade.

Validation requires behavioral dependency-specifier checks that reject known
vulnerable versions and allow patched versions, verification of every captured
advisory range against the new lock, Python 3.12/3.13 support, clean installed
wheels, rendering/parser regressions and the full supported CI/release rehearsal.
Actual versions and final outcomes are recorded in
[PR #139](https://github.com/SkynetRTN/MARS/pull/139) and the
[M6 release evidence](m6-release-evidence.md).

Repository alerts may remain open until the corrected lockfile reaches the
default branch. That status is distinct from whether the release candidate's
versions fall in the affected ranges. This dated assessment does not promise
that new advisories cannot appear; repeat the check when cutting the tag.
